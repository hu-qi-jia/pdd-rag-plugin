## 一、设计原则

1. **白面板 + 细边框**:层级靠 1px #E5E5E5 边框与明度差(#FFF / #FAFAFA / #EFEFEF),不用重描边、不堆卡片。
2. **黑白主色**:主操作黑底白字(#161616);Figma 蓝(#0D99FF)只用于焦点、品牌标与滑杆等状态,不做大色块。
3. **小圆角**:控件一律 4/6/8px,靠近桌面工具软件质感;圆形仅保留给开关、圆点与计数徽标。
4. **行悬浮操作**:列表行的次级操作(编辑/删除/迁移等)默认隐藏,悬浮或键盘聚焦时显现——静止界面只保留主路径。
5. **层级靠字重与字号**:13px 级正文 + 加粗标题 + 灰色辅助,小字号高密度。
6. **禁令**:页面代码不得硬编码字号 / 圆角 / 间距 / 颜色 / 字体,一律引用设计令牌
   (popup 走 ThemeTokens/React 内联;聊天页覆盖层在 CSS 模板里插值同一批令牌)。

**按钮亮暗切换规范**(2026-09-15 v2.6 定稿,参照用户示例图):两种主题**同构映射**,切换主题时按钮不允许跳色
(历史教训:近白主钮过亮 → Figma 蓝与中性色系脱节,最终定稿中性灰):

| variant | 浅色 | 深色 |
|---------|------|------|
| default | 面色底 `#FFF` + 边框 `#D4D4D4`,悬浮 `#FAFAFA` | 面色底 `#2C2C2C` + 边框 `#3B3D40`,悬浮 `#383B3D` |
| primary | 主色底白字 `#161616`,悬浮 `#333` | 面色系提亮一档 `#45484D` 白字,悬浮 `#53565B` |
| danger | `errorBg` 底 + `errorText` 字 | 同浅色(rgba 底自动适配) |

规则:default = 面色 + 边框,悬浮提亮一档;primary = 主色底白字,悬浮再提亮一档;
Figma 蓝只保留给焦点/开关/滑杆等**状态**,不做按钮大色块。

语义色(与主题无关,`design.ts#semantic`):标准回答徽标 amber(`#B8860B` on `#FDF6E3`)、知识库徽标绿(`#14AE5C` on `rgba(20,174,92,.09)`)。

## 四、几何

| 令牌 | 值 | 用途 |
|------|-----|------|
| `radius.sm / md / lg / xl` | **4 / 6 / 8 / 8** | 徽标与图标钮 / 按钮输入框 / 卡片 / popup 外框与浮层 |
| `radius.pill` | 9999 | 仅开关、圆点、圆形计数徽标 |
| `spacing.xs→xxl` | 4 / 6 / 8 / 10 / 12 / 16 | 4 的倍数栅格 |
| `size.popupWidth / popupHeight` | **420** / 560 | popup 固定外框(内容区滚动;v2.4 由 400 加宽,容纳文件夹树层级) |
| `size.railWidth / railBtn` | 52 / 36 | 图标导航栏 / 导航按钮 |
| `controlH.inline / form` | **24 / 26** | 行内小控件 / 表单与工具栏控件(见下) |
| `motion.fast / normal` | 0.12s / 0.15s ease | 悬停 / 开关过渡 |

**控件等高铁律**(2026-09-15 补):同一行内的输入框与按钮必须取同一档高度,
且用**显式 `height`** 而不是靠 `padding + line-height` 撑 —— 后者会随字号/行高漂移,
出现几像素的高低位错(实测:新建子文件夹输入框 35px vs「创建/取消」28px)。
- `controlH.inline = 24`:行悬浮图标钮、行内小按钮(填充/确认/取消)、迁移下拉。
- `controlH.form = 26`:`.pddcs-btn`、工具栏按钮、内联表单(新建/重命名)的输入框与按钮。
- 与按钮同排的输入框走 `components.tsx#controlStyle(tk, controlH.form)`。
- 聊天页覆盖层不享 popup 的全局 `box-sizing: border-box` 重置,注入样式须自带。

## 六、聊天页覆盖层(`contents/pdd-ai-button.ts`)

CSS 为模板字符串,**颜色/字体/圆角/字号全部从 `ui/design` + `ui/theme`(lightTheme)插值导入**,
与 popup 同源;固定浅色(宿主页面不可控,浅色最稳)。

- `.pddcs-ai-btn`:AI回复按钮 —— 与 popup 的 `.pddcs-btn` **同档工具风控件**
  (26px 高 / 6px 圆角 / 12.5px 字号 / 白底细描边 / 悬浮浅灰;纯文字无图标,2026-09-15 用户定)。
  `box-sizing: border-box` 显式声明;位置为气泡真实右缘外 12px。
- `.pddcs-popup`:候选弹窗(8px 圆角 + 浮层阴影 + 4px 方徽标/迷你按钮)。
- `.pddcs-toast`:近黑(#161616 @ .92)轻提示,6px 圆角。

**气泡锚点算法**(2026-09-15 修复「按钮压住气泡」):真机结构
`li.onemsg > .buyer-item > div[currentuid] > .msg-content > p.msg-content-box`,
气泡底色与内边距在上层容器上,`<p>` 的 rect 右缘短掉气泡 padding(实测约 10px)——
按 `<p>` 右缘 +12px 定位,视觉间距只剩约 1px。
现自文本块向上吸收「有不透明背景色 且 宽度贴近文本块(容差 48px)」的最外层祖先作锚,
宽度守卫排除整行容器的底色;兜底取文本块直属容器。算法落在
`src/utils/pddBubbleAnchor.ts`(含单测),内容脚本只做 WeakMap 缓存。

## 七、文件夹模块布局(2026-09-15 重构)

工具风单栏分区树,参照 pddddd 知识库 doc-list 与导航折叠模式:

- **工具栏**:右上角「新建文件夹」直角小钮;新建时原位变内联表单(Enter 提交 / Esc 取消)。
- **根文件夹分区**:可折叠分区头(chevron 旋转 + 文件夹图标 + 名称 + 圆形计数徽标),分区间以细线分隔;「未分类」置底且不可改名/删除。
- **子文件夹**:左侧 1px 引导线缩进,头部字重降为 medium。
- **标准回答行**:分隔线行(非卡片)。问题加粗单行、回复灰色两行、向量状态为行内小字;
  操作分两层——「填充」黑色主钮常驻,复制/编辑/迁移/删除为悬浮显现的 24px 图标钮(删除悬浮红)。
- **一问题多条**:同一问题的标准回答最多 3 条,行内按**设置时间倒序**;
  同问题 >1 条时,问题行右侧标 `同问题 n 条`,达上限追加 ` · 已满`(提示先取消一条)。
- **内联交互**:重命名在分区头原位表单化;删除走内联确认行(常驻可见,不依赖悬浮)。
  内联表单的输入框与「创建/保存/取消」严格等高(`controlH.form = 26`)。
- **重命名入口(v2.6.1)**:悬浮「重命名」图标钮,或**双击文件夹名**直接改名
  (悬浮入口太隐蔽,用户提了"支持修改名称"—— 双击是资源管理器直觉);「未分类」不可改名。

**记忆列表卡片**(同一工具语言):卡片头**问题与元信息居左**,折叠钮移到**行尾**
(chevron,折叠时旋转 -90°,带 `aria-expanded`;整行仍可点击折叠,v2.6.1 用户要求);
展开区与问题文本同左基线(不再为折叠钮留缩进);
回复行常驻「设置标准回答」主钮,成功后就地变绿色对勾「已设为标准回答」。

## 七-A、顶部概览按页签分散(v2.4)

页签标题下的一行小字**只显示与本页相关的计数**(原先四个计数全堆在顶部,与当前页无关):

| 页签 | 概览行 |
|------|--------|
| 记忆 | `问答 n · 回复 m` |
| 文件夹 | `文件夹 k · 标准回答 g` |
| 知识库 | `知识 n` |
| 设置 | **不展示**(行高保留,避免切页签跳动) |

## 七-B、文件夹页分区容器化(v2.4 引入,v2.6 二次重设计)

用户反馈"文件夹的表示混乱":v2.4 用"分区容器 + 引导线"重排后,实机评审发现
引导线(`borderLeft`)与容器边框、行分隔线叠在一起仍然显乱。v2.6 定稿:

- **根文件夹 = 一张分区容器**:1px 边框 + 8px 圆角 + `overflow:hidden`,头部为标题栏
  (常驻 `bgSecondary` 底,高 34,展开时底边 `borderLight`);「未分类」置底用**虚线边框**。
- **层级只靠三件事表达**:统一缩进节奏(`padding-left = 12 + 16×深度`,分区头/子夹行/
  标准回答行/内联表单/空态占位全部同基线)、字重字号(根夹 semibold/body,子夹 medium/secondary)、
  根夹标题栏底色。**不使用引导线与嵌套边框**(v2.6 移除)。
- **子夹与根夹同构**:同一行结构(chevron + 文件夹图标 + 名称 + 计数徽标 + 悬浮操作),
  高 30、透明底、悬浮 `bgSecondary`;仍排在父夹标准回答**之前**(资源管理器直觉)。
- **仅一级文件夹(v2.6.1 定稿)**:子文件夹创建入口移除,「新建根文件夹」更名**「新建文件夹」**;
  历史遗留的子夹数据仍照常展示(同构行)与删除,但不支持再新建 —— 扁平结构比两层树更符合本工具的使用密度。
- **标准回答行**:分隔线行(非卡片),与所在分区头同基线左对齐;「填充」主钮常驻,
  复制/编辑/迁移/删除悬浮显现。
- **空文件夹**:灰字"暂无标准回答"占位(与分区同基线缩进)。
- **工具栏**:「+ 新建文件夹」左对齐,内联新建时原位变表单。

## 七-C、聊天页推荐回复面板(v2.5 引入,v2.6 固定配额组成)

原「AI 候选」面板更名与升级:

- **命名**:面板标题「推荐回复(n)」;得分数字不再展示(对客服无决策价值),同内容折叠数保留。
- **固定配额组成**(2026-09-15 v2.6 用户指定,替代原"融合分截断 + 类别保障"):
  **标准回答全部展示**(同问题本身上限 3)+ **历史取最近 2 条**(按回复时间倒序,与相关度无关)
  + **知识库取 1 条**(相关度最高)。配额在折叠后胜者池上选取
  (`retrieval.ts#PANEL_QUOTA`),某类别候选存在就必然占位,无需事后补位;
  「标准回答优先」开关只影响排序,不影响配额。点击「AI回复」与快捷键唤起的面板**完全同构**。
- **不溢出**:面板挂载后量 `getBoundingClientRect().height` 向上取整,垂直方向整体夹在视口内
  (亚像素高度要用 rect 量,`offsetHeight` 是取整后的整数会差 0.1px 压线)。
- **快捷键**(默认 `Ctrl + Enter`,设置中可录入自定义组合,需带 Ctrl/Alt/Shift):
  - 「自动回复」关:检索**用户最新消息** → 弹推荐回复面板(与点击「AI回复」同构)→ 再按 `Enter` 填充第一条;
  - 「自动回复」开:检索 → 直接填充第一条;
  - 面板由快捷键唤起时脚注提示「按 Enter 填充第一条」;Esc/点外部关闭即解除。
  - 快捷键在设置页展示(`kbd` 样式)+「修改」按钮进入录入态。
  - 行布局(v2.6.1):第一行 = 标签 + `kbd` + 修改钮;说明与录入提示各占**独立一行**
    (`flexWrap` + `flexBasis:100%`)—— popup 宽度有限,四段挤一行会把「快捷键」标签压成竖排。

## 八、文案规范

- 概念命名(2026-09-15 起):「金标准」一律称 **标准回答**;聊天页面板称 **推荐回复**(v2.5,原"AI 候选");
  提升操作按钮为 **设置标准回答**,
  已在标准回答状态时的反向操作为 **取消标准回答**(只解除身份,不动历史记录)。
- 上限提示(2026-09-15):「该问题已有 3 条标准回答,请先取消一条」;成功提示带额度 `已设为标准回答(2/3)`。
- 操作按钮:两字优先(填充 / 复制 / 编辑 / 删除 / 确认 / 取消 / 创建 / 保存 / 启用 / 停用);
  例外:设置标准回答(用户指定全称)、新建文件夹(入口钮)。
- 空状态:「暂无 ××」+ 一句引导。
- 结果提示:动宾结构直述结果;固定表述「发送由人工完成」「后台将自动向量化」。
- 技术细节放 tooltip / title,不挤占界面文案。

## 九、popup 全局样式(注入于 `popup/index.tsx`)

- `.pddcs-btn`:直角基础样式(6px 圆角、边框、过渡);**高度固定 `controlH.form`(26px)**,
  保证与同排输入框/工具栏按钮等高。
- `.pddcs-input`:输入框基础样式(6px 圆角,focus 由内联 border 提亮)。
- `.pddcs-scroll`:悬浮才出现的细滚动条。
