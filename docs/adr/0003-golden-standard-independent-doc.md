# 金标准是提升时复制的独立"标准问答"文档,而非对历史记录的引用

> **状态:核心决策仍有效。** UI 文案现称「标准回答」；分类轴已由 `categories`
> (问题类型)取代旧文件夹，`folders` 只保留用于旧备份导入和迁移兼容。

原项目只有单一扁平消息流(软删除/覆盖语义),无法表达"客服主动沉淀、长期有效、可归文件夹"的知识形态。改造后问答记录有 90 天保留期,而金标准需要永久留存且可独立编辑——若做成引用,TTL 清理与编辑会相互污染。

故:提升金标准 = 复制问答内容为新文档(问题字段 + 回复字段,记录来源问答记录 id),可编辑问题/回复、可删除、可移入文件夹;保存编辑即作废旧向量并自动重嵌入(模型内嵌版本号);删除金标准不影响原问答记录,TTL 清理问答记录不影响金标准。代价是编辑后金标准与原问答记录不再同步——这正是期望语义(金标准是人工精修的标准答案,不是历史快照)。
