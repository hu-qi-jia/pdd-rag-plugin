# Edge 加载项(Add-ons)上架材料与操作清单

- 日期:2026-09-17 · 对应版本 **v0.11.0**(zip:`pdd-cs-quick-reply-v0.11.0.zip`,16.4MB)
- 产物:同一份 `build/chrome-mv3-prod`(Chrome 商店/离线 zip 共用,不分支)

## 一、维护者需要准备的东西(全部免费)

1. **Microsoft 账号**(没有就注册一个);
2. 能直连的浏览器即可 —— Partner Center 国内**无需代理**。

## 二、操作步骤(Partner Center)

1. 打开 `https://partner.microsoft.com/dashboard/microsoftedge`,用 Microsoft 账号登录;
2. 首次进入按提示注册为 Edge 开发者(免费,需一次性身份验证,手机/邮箱即可);
3. 左侧「加载项」→「创建新扩展」;
4. **上传** `pdd-cs-quick-reply-v0.11.0.zip`(一次最多 1GB,我们的 16.4MB 无压力);
5. 按**第三节**填商店元数据(全部可直接复制);
6. **隐私**页:选「此扩展不收集任何用户数据」(见第四节口径,我们的数据仅存用户本机);
7. 提交审核 —— 通常**数小时至数天**;通过后用户即可在 Edge 加载项商店直接安装,自动更新。

**详细描述**:

```
拼多多商家客服的本地检索助手:自动记录商家后台聊天页的买家问答,沉淀为可检索的回复候选;需要时按语义+关键词混合检索历史回复、标准回答与知识库,点击候选一键填充到官方输入框。

功能:
· 自动捕获 —— 客服打开的会话内,买家问题与客服回复自动配对入本地库,保留期默认 90 天(可调);
· 混合检索 —— 向量(bge-small-zh-v1.5,本地推理)+ BM25 双路融合,候选 = 标准回答 + 历史回复 + 知识库;
· 标准回答 —— 优秀回复可提升为标准回答(豁免保留期,文件夹归类);
· 知识库 —— 手工"标题+正文"话术卡与 .md 文档上传(自动分块);
· 一键填充 —— 候选写入官方输入框,发送永远由人工点击,绝不自动发送。

合规与隐私:
· 数据 100% 仅存本机(IndexedDB),不上传任何服务器;
· 检索模型内置扩展包,安装即用、离线可用,运行期零远程请求;
· 不自动群发、不代替人工操作平台功能。

适用对象:拼多多商家客服(需能访问 mms.pinduoduo.com 商家后台)。
```

**权限用途说明**(审核/用户询问时用):
- `storage` / `unlimitedStorage`:本地 IndexedDB 与设置存储(全部数据留在本机);
- `offscreen`:离屏页运行本地嵌入模型推理(不显示任何界面);
- `alarms`:本地数据保留期清理的定时任务;
- `scripting`:向商家后台聊天页注入「AI回复」按钮与候选面板;
- `host_permissions — https://mms.pinduoduo.com/*`:仅商家后台域名,无其他站点。

## 四、隐私口径(审核问询统一回复)

本扩展不收集、不传输任何用户数据;无任何远程网络请求(嵌入模型内置);全部数据仅存用户本机浏览器 IndexedDB,用户可随时在设置页导出或清除。
