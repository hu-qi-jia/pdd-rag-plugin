# v0.15.1 —— AI 整合 + 推荐面板重设计(自 v0.11.0 起的累积更新)

自 v0.11.0 以来的累积更新(v0.12.0 → v0.15.1)。**检索模型仍已内置**,安装后离线可用、首跑无需任何下载;数据 100% 仅存本机,发送永远由人工确认。

## 新增

- **AI 整合(默认关闭)**:推荐面板的知识库候选上方多一行「根据知识库内容整合并回复」,**点击才**把本轮命中的知识库内容与买家问题发给你自己配置的接口(OpenAI 兼容 / SSE 流式),生成的回复流式填进输入框 —— 发送仍由你手动点。设置页含接口地址 / 密钥 / 模型 / 超时与「测试连接」(401/403 报密钥、404 报地址或模型名、429 报额度),密钥只存本机、不同步云端。生效条件见 `docs/adr/0006-optional-llm-integration.md`:不配置、不开启时扩展保持完全本地,历史回答与标准回答永不外发

## 修复

- **问答体 `.md` 文档检索不到**:分块器只按 `#` 标题切,整篇问答被并成一块,向量被多个主题平均稀释,跌破阈值后在排序第一步就被丢掉,BM25 根本没机会参与 —— 表现为"知识库明明有这条,问起来永远匹配不上"。现按问答对切分,实测「防水吗」相似度 0.391 → **0.709**
- **AI 接口配置保存后内容全消失、整块不可用**:表单字段名(`baseUrl`)与设置字段名(`llmBaseUrl`)不一致,保存时一个字段都没落库,回填又拿旧设置把输入框清空。字段映射现收敛到单点
- **「整合超时」滑杆拖不动、读数荒唐**:滑杆读秒、量程是秒,而喂进去的是毫秒(默认 8000),值恒大于上限 —— 浏览器把滑块钉在最右端,拖动时新值落库又变回毫秒、再次越界,观感就是"拖不动",读数还写着「8000 秒」。现两侧同单位,默认 **8 秒**

## 改进

- **推荐回复面板重做**:Apple 式磨砂浮层(半透明底 + `backdrop-filter`、去描边、圆角 20px、留白单源),层次与定位一并校正
- **面板字型立规**:三档字号(15 / 13.5 / 11.5)+ 两档字重(600 / 400),不再有相邻只差 1px、说不出理由的档位
- **整合行**:与词条等高、知识库绿软底与素材一眼区分;生成结果按正文口径排版;**填完即退场**(填不进去时留在面板里,方便手动复制)
- **关闭钮收成裸 ×**(可点范围不变),设置页去掉三行冗余说明
