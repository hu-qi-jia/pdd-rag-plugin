# v0.16.0 —— 使用统计 + 待沉淀清单 + 导出带上文档原文

本次三件事都不是"再加一个功能",而是把**已经有了、却说不清 / 接不上 / 搬不走**的三处补齐。**检索模型仍已内置**,安装后离线可用、首跑无需任何下载;数据 100% 仅存本机,发送永远由人工确认。

## 新增

- **「沉淀」页签 —— 哪些问题问得最多、却还没有标准回答**

  历史记录按保留期自然衰退,同一件事问得越多,越说明它值得固化成标准回答 —— 这个页签就是把那批问题挑出来,按**出现次数倒序**(只按时间排会让"新问的一次性问题"盖住高频问题)。

  每条给出该问题最近一次的回复,**一键设为标准回答**(并记下这条答复是从哪来的);同一个问题答过几种说法的,「换一条」展开挑选。不需要沉淀的点「不再提示」,它就不再出现 —— 历史记录与标准回答都不受影响,这个"不再提示"是记在本机的,下次打开仍然不提示。**提升之后该问题会自动从清单里消失。**

  挑选用的是归一化的**精确文本**匹配:「能不能退货」和「可以退货吗」暂时算两条(语义合并留到后续版本)。页面上如实写着这条口径,而不是假装已经合并了。

- **设置页「使用统计」—— 这工具到底帮上忙没有**

  此前没有任何办法回答这个问题:检索准不准、候选真被填过几次、AI 整合有没有人用,全靠感觉。现在本机记六类计数:检索次数与其中未命中、面板打开(点击 / 快捷键)、四类填充(标准回答 / 历史回答 / 知识库 / AI 整合);检索那一行会把未命中率一起算出来,写成一整句,如 `40 次 · 未命中 10 次(25%)`。

  没检索过时**不显示百分比**(分母都没有,写 `0%` 是在编数字);一次都没用过则显示一句话,而不是留一排 `0 次`。标准回答与知识库的每一条、每一段还会各自记"被填入输入框几次",在文件夹页与知识库页的卡片上标出(只显示真正被用过的)。

  「重置统计」只清计数,**任何业务数据都不动**。卡内写明边界:**只记在本机,不联网、不随导出外发。**

## 修复

- **导出的包现在带上了知识库文档原文**。此前导出只带"切好的知识块",不带原文 —— 换台机器导入后,如果分块规则已经升级过,自动重切这条链在新机器上是断的,只能看到"请重新上传原文"的提示,而原文一直就在你手里。现在原文与分块器版本一起随包走,导入后照常自动重切,**不必重传**。同一个文档名在本地已有原文时**跳过而不是覆盖**(本地那份可能已经被你重传成了新内容)。新增字段全部可选,旧版本导出的包照常导入。
- **修掉一处会把"重传整篇文档"和"自动重切"一起弄坏的内部错误**。逐条用量要跟着条目走,而删除文档块的实现里新开了事务 —— 与整篇重传、自动重切各自的外层事务撞上,两条路会直接抛错。已合并为同一个原子事务。
