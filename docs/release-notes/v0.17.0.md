# v0.17.0 —— 问题类型自动分类 + 尺码推荐 + 推荐面板来源标签

自 v0.15.1 以来的累积更新(v0.16.0 → v0.17.0)。**检索模型仍已内置**,安装后离线可用、首跑无需任何下载;数据 100% 仅存本机,发送永远由人工确认。

## 新增

- **问题类型自动分类(默认关闭,ADR-0007)**

  捕获与提升时,把问题文本发给你自己配置的 TypeSafe 接口,归入八个记录级类型(商品信息 / 价格优惠 / 库存与规格 / 支付与发票 / 发货与物流 / 退换货 / 质量与维修 / 其他),判不准的落「未分类」,不猜。可在「记忆」「标准回答」两页按类型筛选与收窄检索。

  「尺码推荐」是**查询级专用**类型:照常参与意图识别,但不会成为某条历史记录的标签。存量数据可在设置页点「开始分类所有历史」补齐(只发问题文本,不发回复正文)。**不开这个开关时,分类不会发生、也不会发任何请求。**

- **尺码推荐:上传一份尺码表,直接给买家一个码**

  知识库页新增「上传尺码表」。被标记的文档**整篇原文不参与向量检索** —— 买家的身高体重往往落在两行边界上,检索容易只命中其中一行;整表喂给模型,让它自己对着挑。面板会出现「根据尺码表生成回复」行,点击后生成一段带**具体尺码**的话术,例如「建议穿 M 码,体重 90-110 斤对应 M 码」。

  同一时刻只保留一份尺码表(传新的会自动替换旧的标记)。尺码回答有独立提示词:以体重为主、身高只作校验;只有尺码表**明确写了**超出范围时才建议联系客服,不会再把买家推去转人工。

- **推荐回复面板:来源标签一眼分清**

  标准回答、历史、知识库改用**不同颜色的矩形标签**:标准回答赭陶、知识库绿、历史中性灰,深色主题各有一套对应值。不再是 `[历史]` 这种方括号注记。

- **使用统计 + 导出带上文档原文(0.16.0)**

  设置页记录检索次数、未命中次数、面板打开与四类填充计数;「重置统计」只清计数,不动业务数据。导出包现在同时带上知识库文档原文与分块器版本,换机器导入后自动重切,**不必重新上传**。

- **AI 整合兼容性**

  对 DeepSeek 端点显式关闭思考模式(其 V4 起默认开启),避免思维链占满输出预算导致「整合结果为空」;其它 OpenAI 兼容接口不受影响。

## 修复

- **「根据尺码表生成回复」报「整合结果为空」**:DeepSeek 默认思考模式导致流里只有思维链、没有正文,已显式关闭;
- **尺码回答让买家「联系客服确认」**:尺码路由此前复用知识库的保守提示词,现改为专用提示词,必须报出具体尺码;
- **推荐回复面板右侧常驻一条空白**:移除滚动容器的 `scrollbar-gutter` 预留槽位,选中行的底色现在直达右缘;
- **取消尺码表标记时确认文案被挤成一字一列**:确认条改为独占整行。

## 数据与兼容

- 数据库 schema 升到 v9(问题类型集迁移),旧数据在首次启动时自动迁移,标准回答、历史问答与知识库均保留;
- 导出文件新增字段全部可选,旧版本导出的包照常导入;导入到本版本后会按当前分块器自动重切。
