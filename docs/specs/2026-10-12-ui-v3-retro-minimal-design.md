## 一、背景

v2.6 / v2.7 的视觉是「Figma 编辑器工具风」：白面板 + 24px 大圆角 + 1px 浅灰描边 + Figma 蓝焦点 + 卡片套卡片；聊天页推荐面板在第四十九轮进一步走到 Apple 毛玻璃（半透明材料 + backdrop-filter + 阴影定轮廓）。

四十六轮迭代下来，这套语言在 popup 这种 420×560 的小窗口里只剩三个后果：

1. **层级靠"再加一层容器"** —— 卡片套行、行套徽标、徽标套软底，四层底色叠在一起，真正要读的正文反而最不显眼；
2. **文字在解释界面** —— 设置页每张卡都挂了 2~3 句"这段数据发给谁、密钥存在哪"的说明段，知识库卡底部还挂着一整句检索层级说明；用户读的是说明，不是设置项；
3. **两种语言并存** —— popup 是圆角卡片，聊天页面板是毛玻璃浮层，同一件事（一条候选）在两个地方长得完全不像。

v3.0 换一套**减法**语言：黑白灰 + 等宽字 + 全直角 + 线重即层级 + **反白 = 当前所在**。卡片不再靠底色分层，靠 1px 线切开；层级不再靠灰阶堆叠，靠字号（13 / 12 / 11.5 / 10 四档）；颜色只剩一个（琥珀 = 金标），其余全部退出。

## 二、目标与非目标

### 目标

1. popup 四页 + 聊天页推荐面板统一到 v3.0 一套令牌、一套手势
2. 记忆页与标准回答页的**分类从页内分区标题改为顶部导航栏**（方案 A 墨块）
3. 记忆页问题行**默认折叠**，点击展开回复；每条回复行尾挂 `☆ 设标准 / ⧉ 复制`
4. 修掉「记忆页只能设标准、不能取消」—— ★ 改为双向开关
5. 尺码表由「每块一个开关」改为「上传按钮 + 上传即可」
6. 设置页删掉解释性长段，只留控件与标签
7. 行内文字与容器做减法：删掉零信息量标签、"本页即 X"式冗余徽标、重复的说明句

### 非目标（本次明确不做）

- **不改任何数据模型**。`categories` / `goldens.categoryId` / `kbDocs.isSizeTable` / `metrics` 表结构与字段一律不动
- **不改检索、路由、分类、导入导出、埋点的任何逻辑**（唯一例外见 §7.2：尺码表的**写入路径**从 Toggle 改为上传入口，落库字段不变）
- **不换图标库**。继续用 lucide-react / lucide SVG 字面量
- **不改图标的圆头线帽**（lucide 的 `stroke-linecap: round` 与 `rx=2` 保留）：要让图标也全直角需手写 path，而 12~13px 下圆头与方头肉眼无差 —— 收益为零，改造成本与维护成本都不小
- **不做动效体系**。v3.0 只在悬浮/选中态保留 0.1~0.12s 的颜色过渡，不做位移、不做入场动画
- **不改 popup 高度**（560px 维持）

## 四、设计语言 v3.0

### 4.1 色板

**浅色（纸）**

| 令牌 | 值 | 用途 |
|---|---|---|
| `paper` | `#ffffff` | 面板底（唯一底色，全站没有第二种卡片底） |
| `ink` | `#111111` | 页面名、问题行、答案锚、结构线、选中实心 |
| `ink2` | `#444444` | 回复正文、答案正文 |
| `ink3` | `#777777` | 次级说明、导航未选中、文字钮 |
| `ink4` | `#9a9a9a` | 元信息、计数、占位、序号 |
| `line` | `#e5e5e5` | 结构线（外框、状态条收口、分区收口） |
| `lineS` | `#f0f0f0` | 发丝行线（行与行之间） |
| `fill` | `#f5f5f5` | 悬浮底（唯一的一种"软底"，v2.6 那六种软底全部退役） |
| `fillSoft` | `#fafaf8` | 展开区/卡片悬浮底（比 `fill` 再轻一档） |
| `amber` | `#8a6a16` | **唯一语义色**：金标、已设标准 |
| `danger` | `#a02c1c` | 错误、危险操作（印刷红，替代原 Figma 红 `#f24822`） |

**深色（墨）**

| 令牌 | 值 |
|---|---|
| `paper` | `#111111` |
| `ink` | `#ededed` |
| `ink2` | `#b8b8b8` |
| `ink3` | `#8a8a8a` |
| `ink4` | `#6b6b6b` |
| `line` | `#333333` |
| `lineS` | `#262626` |
| `fill` | `#1c1c1c` |
| `fillSoft` | `#181818` |
| `amber` | `#d4a94a` |
| `danger` | `#e06b5a` |

**"反白"的两种主题实现**：浅色 = `ink` 底 + `#fff` 字；深色 = `ink` 底（即近白）+ `paper` 字（即近黑）。同一个令牌对，方向自动相反 —— 与 v2.6 的 `controlKnobBg` 反相是同一个道理。

**退役的颜色**：`accent` / `accentHover`（Figma 蓝）、`semantic.knowledge*`（知识库绿）、`successBg` / `successText`（绿软底）、`surfaceOverlay` / `knowledgeSurface*`（毛玻璃材料）。焦点环改 `ink` 1px。

### 4.2 字型与字号

**字型栈**（`design.fontFamily`）：

```
ui-monospace, "SF Mono", "Cascadia Code", "JetBrains Mono",
Consolas, "Courier New", monospace, "Microsoft YaHei", sans-serif
```

拉丁字母与数字落在等宽字上（序号、计数、时间、百分比、快捷键），中文回落雅黑 —— 这就是"极客工具"的读感来源，不需要为中文找等宽字体。

**字号阶梯**（四档，等差 +1.5 / +1.5 / +1.5 → 实际取整）：

| 档 | 字号 | 用途 |
|---|---|---|
| `title` | 13 | 页面名、折叠行的问题、标准回答卡的问题、Q/A 字母锚 |
| `body` | 12 | 标准回答的答案正文、知识库卡正文、输入框 |
| `secondary` | 11.5 | **记忆页回复正文**、分类导航项、文字钮、次级说明 |
| `meta` | 10 | 元信息、计数、序号、灰标、脚注、键帽 |

记忆页的回复正文取 `secondary` 而非 `body`：折叠行展开后一屏要放下多条回复，11.5px 是稿子里命令台的取值（`UI设计稿-方向探索` D1 `.cmd-open .r`）。标准回答页的答案是"成品"，用 `body`。

比 v2.6 的 `10.5 / 11.5 / 12.5 / 13.5 / 15` 五档**少一档、整体下移**。页面名从 15 降到 13 —— 状态条靠 3px 墨条与右侧计数立住，不靠字号。

**字重**：`regular 400` / `semibold 600`。v3.0 下 500 全站退役（与 panelType 同口径）。

**数字**：所有计数、时间、耗时一律 `font-variant-numeric: tabular-nums`。

### 4.3 几何

- **圆角全 0**。`radius` 令牌整体退役（`sm/md/lg/xl/xxl/pill` 全删），页面不得再出现任何 `borderRadius` 字面量。开关滑块与滑杆拇指改**方形** —— 方轨配方柄，是"全直角"的必然推论；圆形柄压在方形轨道上会露出"上一版语言的残留"
- **线宽只有两档**：结构线 `1px line`，发丝线 `1px lineS`。**线重即层级** —— 面板外框、状态条收口、导航收口用 `line`；行与行之间用 `lineS`
- **不使用阴影**。`tk.shadow` 退役；浮层靠 1px 墨框与页面分开
- **不使用背景模糊**。`material` 令牌退役
- **间距**沿用 `spacing` 栅格（4/6/8/10/12/16），不新增
- **控件高度**：`controlH.inline = 24`（图标钮、内联确认行）、`controlH.form = 26`（按钮、输入框）。图标钮在 v3.0 收成 **20×20**（图标 12px），新增 `controlH.icon = 20`

### 4.4 交互语言

只有四条规则，全站一致：

1. **反白 = 当前所在** —— 选中的分类导航项、选中的列表行、悬浮的图标钮、悬浮的文字钮，一律墨底白字
2. **悬浮 = 浅底** —— 可点但未选中的元素，悬浮给 `fill` 底 + `ink` 字
3. **主钮 = 墨底白字，一页只有一个**。标准回答页是「＋ 新建类型」，知识库页是「＋ 新建条目」。设置页**没有页级主钮** —— 两张配置卡（AI 整合 / 问题分类）的「保存」平时是描边钮，仅在该卡有未保存修改时才呈现墨底白字（把"主钮态"绑在"有事可做"上，顺带让"有没有改动"一眼可见）。其余按钮一律描边钮或图标钮 —— 卡片上常挂主钮的话，一屏十几个黑块，主钮就不成其为主钮了
4. **描边钮 = 1px 墨框 + 墨字**，悬浮反白（「＋ 设为标准」这类）

过渡：`0.12s` 颜色过渡；无位移、无缩放、无入场动画。

**键盘可达性不降级**：开关、滑杆、导航项、行内钮的 `tabIndex` / `focus-visible`（`1px ink` 外环，`outline-offset: 2px`）原样保留。键盘焦点环是 v3.0 里唯一"方框套方框"被允许的地方。

## 五、令牌落地

### 5.1 `src/ui/theme.ts`

重写 `ThemeTokens` 接口为 v3.0 语汇，`lightTheme` / `darkTheme` 按 §4.1 重估。

**删除字段**：`bgSecondary` `bgCard` `separator` `accent` `accentHover` `selectedBg` `btnBg` `btnBorder` `btnHoverBg` `btnPrimaryBg` `btnPrimaryHover` `btnPrimaryText` `successBg` `successText` `inputBg` `inputBorder` `switchTrack` `switchTrackHover` `controlActive` `controlActiveHover` `controlKnobBg` `shadow` `surfaceOverlay` `fillQuiet` `fillQuietHover` `knowledgeSurface` `knowledgeSurfaceHover`
**保留并重估**：`bg`→`paper`、`text`→`ink`、`textMuted`→`ink3`、`textTertiary`→`ink4`、`border`→`line`、`errorBg`/`errorText`/`errorHoverBg`→`danger*`、`scrollThumb`
**新增**：`ink2` `fill` `fillSoft` `amber` `amberSoft` `inverseInk`（反白时的字色）

v2.6 那批"输入框专用"令牌（`inputBg` / `inputBorder`）随之删除：v3.0 下方框一律 `paper` 底 + **`ink` 1px 框**，没有第三种框色；滑杆未填充段改用 `line`。

改名的理由：现有字段名里有一半直接编码了正在废弃的语言（`accent` 是 Figma 蓝、`surfaceOverlay` 是毛玻璃、`knowledgeSurface` 是知识库绿、`bgCard` 是"卡片套卡片"）。留着死名字比改名的成本更高。改名由 `tsc` 全程护航，编译器会点出每一个消费点。

## 十一、风险与未决

### 风险

1. **P1 是全局改动，改完到 P6 之间界面处于"半新半旧"状态** —— 靠分阶段把中间态压短：P1 结束时四页应当是"v3.0 骨架 + 旧内容结构"，可看但未完成
2. **令牌改名波及 19 个测试文件** —— 由 `tsc` 与 vitest 全程兜底，不做"新旧字段并存"的过渡层（过渡层会让死名字活得更久）
3. **聊天页面板是注入平台页的 CSS**，v3.0 撤掉 `backdrop-filter` 后要确认在浅色平台页上 1px 墨框是否足够把面板与页面分开 —— 这是 P6 唯一需要真机看的一条
4. **`popupWidth 460`** 在 1366 宽笔记本上仍宽裕，但若你的 Chrome 有缩放，可能显得偏大 —— 单点可回退
