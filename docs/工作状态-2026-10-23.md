## 〇、2026-10-22~23:设置档位 / 知识库模板 / UI 打磨(单测 971/971(74 文件),tsc 0 错,build 过)

这一轮的前半段(10-22)完成于对话之外:三个相似度阈值改成 `低/中/高`、保留期改
`7天/30天/90天/自定义`、知识库加模板下载、设置页按钮与文案收口、文档升 v5.0。
后半段(10-23)按用户实测反馈做四处调整。

### 一、保留期档位卡死(修复)

- **现象**:保留期已是 90 天 → 点「自定义」→ 点回「90天」,选中态仍停在「自定义」,
  下方自定义输入行也不收起。
- **根因**:`onChange` 的预设分支只 `persist`、不改 `retentionMode`;而同步 effect 的依赖是
  `draft.retentionDays`,90→90 没有变化,effect 不重跑,于是状态停在 custom。
  只有"切到一个不同的预设值"才会被 effect 救回来。
- **修复**:点击时先 `setRetentionMode(choice)`,再落库。回归断言在
  `tests/unit/ui/settingsPreferences.test.tsx`(自定义 → 同值预设)。

### 二、知识库模板占位过大(调整)

模板下载从"工具栏下方一整行按钮"改成一行文字链(`pddcs-linkbtn`),去掉「模板」
前缀标签,图标 14 → 12,行高 28 + 12 内边距降到 17 + 8。省约 16px,视觉重量也回到
次级操作该有的位置。仍是纯本地 Blob 下载,不发后台消息(既有断言未改)。

### 三、设置页文字档位"没有背景"(调整)

起因是轨道底用的是 `fill`,而设置行是白卡 `surface`,两者只差 1.09:1 ——
界面上看起来是一排裸字,只有选中项孤零零一块白。现在:

- 轨道:`fill` + `border` 内描边 + 轻内阴影,整组读作一条控件;
- 选中:`accentSoft` 底 + `accentText` 字 + 中等字重(与规范第③条"选中是淡底"一致);
- 悬浮:未选中项给 `selection` 底。
圆角只用 `radius.control` 一档 —— `popup-css.test.ts` 会拦下任何临时半径值。

### 四、全局字体(调整)

`design.ts#fontFamily` 改成 `system-ui` 打头的浏览器/系统默认无衬线栈,
`popup-css` 把 `html/body` 与 `button/input/textarea/select` 一起接上(原生控件不继承字体,
不接就会退回 Times)。等宽栈 `fontFamilyMono` 不变,仍只用于数字、时间戳、键帽。

### 六、主色调:v5.0 暖纸 → v5.1 石墨蓝灰

- 先做了四个候选各一页示意(浅色 + 深色并排,`build/palettes/*.html`,随手生成、不入库),
  用户选「石墨蓝灰」:页底 `#ECEDEF`、卡面纯白、靛蓝强调 `#2F5FA8` / 文字版 `#274E8C`。

- 取色是按断言反解的,不是挑手感:浅色三级 `#656B73` 对页底 4.59:1、对卡面 5.38:1;
